# Roadmap

Prazo indeterminado, sem orçamento. Marcos por entrega jogável, não por data.

| Marco | Entrega | Critério de pronto |
|---|---|---|
| M0 — Fundação | Projeto, regras puras, testes, skills, GDD | Testes de regra passam headless |
| M1 — Combate-piloto | Grade tática, iniciativa, ataque, dano pela fórmula de defesa | Uma batalha 1x1 jogável |
| M2 — Grupo | Party até `PARTY_MAX_SIZE`, ações de turno completas | Batalha 4x4 com reação e movimento |
| M3 — Personagem | Classes, origens, espécies, multiclasse, nível até 5 | Criar personagem e subir até nível 5 |
| M4 — Exploração e diálogo | Mapa com interação, testes de habilidade, árvore de diálogo com flags | Um ato com escolhas que mudam estado |
| M5 — Vertical slice (MVP) | Fluxo completo: exploração, combate, diálogo, save | Jogável do início ao fim do ato 1 |
| M6 — Co-op | Sessão de rede para o grupo | Dois jogadores completam o ato 1 |
| M7 — Mobile | Porte e ajuste de controles | Build mobile rodando o ato 1 |
